# Repository instructions

- This repository is Anthony Hayes's quantitative trading and research portfolio.
- Quantitative trading is the primary positioning; quantitative research is secondary.
- Factual accuracy is more important than impressive wording.
- Project specifications and blueprints do not prove implementation.
- Every project requires an evidence-based status: Blueprint, In development, Implemented or Validated.
- Performance, completion, profitability, live-trading, dataset, latency and statistical-significance claims must not be invented.
- Maintain project content through `assets/data/projects.js`; do not copy project markup by hand.
- Public project documents may be stored under `docs/projects/` and linked through `documentLinks` or `reportUrl` after privacy and factual review.
- Keep the homepage to two to four strong featured projects.
- Emphasise research questions, assumptions, evaluation, frictions, risk controls and limitations over technology lists.
- Keep the site restrained, professional, mobile-friendly and recruiter-scannable.
- Do not publish Anthony's telephone number, private CV file, personal 104.8% return figure, private account information or investment recommendations.
- Do not deploy visible placeholders.
- Preserve the existing GitHub Pages static setup; do not migrate frameworks or add significant dependencies without explicit approval.
- Run relevant checks after changes, including link rendering, mobile layout, accessibility basics and JavaScript behaviour where the environment supports them.
- Future agents must report exactly which checks they ran and any remaining limitations.
